## Gemini CLI 사용 가이드

### 📋 기본 옵션

**핵심 옵션:**
- `-m, --model`: 모델 선택 (기본값: "gemini-2.5-pro")
- `-p, --prompt`: 프롬프트 (stdin 입력에 추가)
- `-s, --sandbox`: 샌드박스 모드 실행
- `-d, --debug`: 디버그 모드 (기본값: false)
- `-a, --all_files`: 모든 파일을 컨텍스트에 포함 (기본값: false)
- `-y, --yolo`: 모든 액션 자동 승인 (기본값: false)
- `-c, --checkpointing`: 파일 편집 체크포인트 활성화 (기본값: false)

**고급 옵션:**
- `--show_memory_usage`: 상태바에 메모리 사용량 표시
- `--sandbox-image`: 샌드박스 이미지 URI
- `--telemetry`: 텔레메트리 활성화
- `--telemetry-target`: 텔레메트리 대상 (local/gcp)

### 🎯 워크플로우 프로세스

#### 1. 작업 분석 단계
- 사용자 요청을 파싱하여 작업 유형 식별 (코드분석/리뷰/리팩토링/문서작업)
- 범위와 컨텍스트 결정 (특정 파일, 폴더, 또는 전체 프로젝트)
- `CLAUDE.md` 컨텍스트 추가
- 모호함이 있을 경우 명확화

#### 2. 명령어 준비 단계
- 작업 유형에 적합한 Gemini 옵션 조합 선택
- 파일 경로 또는 패턴 준비
- 적절한 모델 및 실행 모드 결정

#### 3. 실행 단계
- Gemini 명령어 실행
- 실행 진행상황 모니터링
- 출력 캡처 및 처리
- 오류 상황 우아하게 처리

#### 4. 결과 전달 단계
- 발견사항을 종합적으로 정리 및 우선순위화
- 상세하고 구조적인 형식으로 결과 제시
- Gemini 분석의 증거와 추론 포함
- 도움이 되는 곳에 코드 예제 포함
- 다음 단계 또는 개선사항 제안


### 📚 Claude Code 통합 호출 방법

#### 기본 분석 패턴
```bash
Bash(
  command='gemini -p "<변환된 $ARGUMENTS>" -d',
  description="Gemini CLI 기본 분석",
  timeout=180000
)
```

### 🔧 프롬프트 변환 가이드라인

**입력 프롬프트 최적화:**
1. `$ARGUMENTS`를 작업 유형에 맞게 구체적으로 변환
2. 컨텍스트 정보 (파일, 범위, 목적) 명시
3. 예상 출력 형식 및 세부 요구사항 포함
4. **프로젝트 루트 경로 자동 포함**: `$(pwd)`를 사용하여 현재 작업 디렉토리 전달
5. **필요 문서 동적 경로 지정**: `$(pwd)/CLAUDE.md` 형태로 상대 경로를 절대 경로로 변환
6. "한국어로 답변" 지시 추가

**작업 유형별 변환 예시:**

**코드 분석:**
```
입력: "이 코드 분석해줘"
변환: "현재 파일의 코드 품질, 성능, 보안성을 분석하고 개선점을 구체적인 예시와 함께 한국어로 제시해주세요."
```

**코드 리뷰:**
```
입력: "코드 리뷰해줘"
변환: "최근 변경사항을 중심으로 코드 리뷰를 수행하고, 발견된 이슈를 심각도별로 분류하여 수정 방안과 함께 한국어로 답변해주세요."
```

**리팩토링:**
```
입력: "리팩토링해줘"
변환: "클린 코드 원칙과 SOLID 원칙을 적용하여 코드를 리팩토링하고, 변경 사항과 개선 효과를 단계별로 한국어로 설명해주세요."
```

**문서 작성:**
```
입력: "문서 만들어줘"
변환: "코드베이스를 분석하여 사용법, API, 설치 방법이 포함된 종합적인 문서를 마크다운 형식으로 한국어로 작성해주세요."
```


### 📊 커뮤니케이션 가이드라인

- **언어**: 항상 자연스러운 한국어로 응답
- **기술 언어**: 명확하고 전문적인 기술 용어 사용
- **컨텍스트**: Gemini 분석 결과를 맥락에 맞게 설명
- **중요도**: 발견된 이슈의 심각도 수준 포함 (Critical/High/Medium/Low)
- **실행 가능성**: 구체적이고 실행 가능한 권장사항 제공
- **단계별 접근**: 복잡한 작업은 단계별로 나누어 설명
