## 메시지 작성 규칙

### 1. 제목 라인 (필수)
- **길이**: 50자 이내 권장
- **시제**: 현재시제 사용 ("추가함" ❌ → "추가" ✅)
- **마침표**: 제목 끝에 마침표 사용 안 함

### 2. 본문 (선택사항)
- **공백 라인**: 제목과 본문 사이 한 줄 공백
- **설명**: 변경 이유, 해결된 문제, 영향도 설명
- **길이**: 72자 단위로 줄바꿈

### 3. 상세 설명이 필요한 경우
```
🔧 파인튜닝 파이프라인 TRL 표준화

기존 수동 포맷팅 방식을 TRL의 apply_chat_template로 교체:
- 배치 처리 효율성 35% 향상
- 특수 토큰 처리 정확도 개선
- 모델별 chat template 자동 적용

관련 파일: test_finetune_mini.py, test_finetune_base.py
테스트: KT-Simple-QA 벤치마크 통과 (86.7% 정확도)
```
