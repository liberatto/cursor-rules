## 브랜치 통합 작업

**목표**: 현재 브랜치의 모든 변경사항을 타겟 브랜치에 통합하여 하나의 커밋으로 생성

### 1. 사전 검증

**필수 확인사항**:

- 현재 브랜치명과 타겟 브랜치 존재 여부 확인
- 작업 디렉토리 상태 점검 (uncommitted changes 경고)
- 브랜치 간 차이점 존재 여부 확인

### 2. 브랜치 전환 및 적용

**변경사항 적용**:

- 타겟 브랜치로 체크아웃
- 소스 브랜치의 모든 파일 상태를 타겟 브랜치에 적용
- 변경사항을 스테이징 영역에 추가

### 3. 통합 커밋 생성

**통합 커밋 메시지 형식**:

```
# 변경 내용 요약 

🔧 주요 변경: [주요 파일들의 변경 내용 요약 & 타겟 브랜치와의 차이점 요약]...
```

**커밋 실행**:

- 생성된 통합 커밋 메시지로 커밋 실행
- 커밋 성공 여부 확인

### 4. 완료 및 후속 조치

**완료 보고**:

- 통합 완료 메시지 출력
- 생성된 커밋 해시 표시  

## 실행 원칙

1. **간결성**: 필수 단계만 수행하여 빠른 실행
2. **명확성**: 핵심 정보만 포함한 간소한 피드백  
3. **안전성**: Git의 기본 기능을 활용한 안전한 작업
