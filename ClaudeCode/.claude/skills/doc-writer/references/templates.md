# Document Templates

문서 타입별 구조 템플릿. 각 섹션은 `[필수]` 또는 `[선택]`으로 표시.

---

## PRD — 제품 요구사항

```markdown
# {제목}

## 1. 배경 & 문제 정의 [필수]
해결하려는 문제와 현재 상황

## 2. 목표 & 성공 지표 [필수]
달성 목표와 정량적 측정 기준

## 3. 사용자 스토리 [필수]
주요 사용자 시나리오 (As a... I want... So that...)

## 4. 요구사항 [필수]
### 필수 (Must-have)
### 선택 (Nice-to-have)

## 5. 비기능 요구사항 [선택]
성능, 보안, 확장성 등

## 6. 제약 & 의존성 [선택]
기술적/비즈니스 제약사항

## 7. 타임라인 [선택]
마일스톤 및 일정
```

---

## PLAN — 구현 계획

```markdown
# {제목}

## 1. 목표 [필수]
구현 대상과 완료 조건

## 2. 현황 분석 [필수]
현재 코드/시스템 상태 파악

## 3. 구현 전략 [필수]
접근 방식과 아키텍처 결정

## 4. 단계별 실행 계획 [필수]
### Phase 1: ...
- [ ] Step → verify: ...
### Phase 2: ...
- [ ] Step → verify: ...

## 5. 리스크 & 대응 [선택]
예상 리스크와 완화 방안

## 6. 의존성 [선택]
외부 의존성, 선행 작업
```

## RESEARCH — 리서치 결과

```markdown
# {제목}

## 1. 조사 배경 & 범위 [필수]
왜 조사하는가, 어디까지 다루는가

## 2. 조사 방법 [필수]
출처, 도구, 접근 방식

## 3. 조사 결과 [필수]
### 옵션 A: ...
### 옵션 B: ...
### 옵션 C: ...

## 4. 비교 분석 [필수]
| 기준 | 옵션 A | 옵션 B | 옵션 C |
|------|--------|--------|--------|

## 5. 결론 & 추천 [필수]
근거 기반 추천

## 6. 참고 자료 [선택]
출처 링크, 문서
```

## REPORT — 상태/진행 보고

```markdown
# {제목}

## 1. 요약 [필수]
핵심 사항 3줄 이내

## 2. 진행 현황 [필수]
### 완료
### 진행 중
### 미착수

## 3. 주요 성과 [필수]
정량적 결과 위주

## 4. 이슈 & 리스크 [선택]
블로커, 주의 사항

## 5. 다음 단계 [필수]
향후 액션 아이템
```

## GUIDE — How-to 가이드

```markdown
# {제목}

## 전제조건 [필수]
필요한 환경, 도구, 버전, 권한

## 1. {단계 1 제목} [필수]
구체적 실행 방법 + 코드/명령어 예시

## 2. {단계 2 제목} [필수]
...

## N. {단계 N 제목}
...

## 검증 [필수]
정상 동작 확인 방법

## 트러블슈팅 [선택]
자주 발생하는 문제와 해결법
```

## ANALYSIS — 기술 분석

```markdown
# {제목}

## 1. 분석 대상 & 목적 [필수]
무엇을, 왜 분석하는가

## 2. 분석 방법 [필수]
사용한 도구, 데이터, 접근법

## 3. 분석 결과 [필수]
데이터/근거 기반 결과

## 4. 원인 분석 [필수]
(해당 시) 근본 원인 파악

## 5. 권장 사항 [필수]
분석 결과 기반 액션

## 6. 영향도 [선택]
변경 시 영향 범위
```

## ADR — 아키텍처 결정 기록

```markdown
# {제목}

## 상태 [필수]
제안 | 승인 | 폐기 | 대체됨 (by ADR-xxx)

## 맥락 [필수]
결정이 필요한 배경, 제약 조건, 요구사항

## 검토한 대안 [필수]
### 대안 1: ...
### 대안 2: ...
### 대안 3: ...

## 결정 [필수]
선택한 방안과 근거

## 결과 [필수]
### 긍정적
### 부정적
### 중립적
```

## NOTE — 간단 메모

```markdown
# {제목}

자유 형식. 필수 구조 없음.

권장 구조 (선택):

## 요점
핵심 내용

## 상세
부연 설명

## 액션 아이템
후속 조치 (해당 시)
```
