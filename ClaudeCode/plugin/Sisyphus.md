

## Sisyphus 멀티에이전트 오케스트레이션

> **Oh-My-Claude-Sisyphus** 플러그인 기반 멀티에이전트 시스템 활성화

### 기본 동작 모드

이 프로젝트에서는 **Sisyphus 오케스트레이션 모드**가 기본으로 활성화됩니다:
- **스마트 위임**: 복잡하거나 전문화된 작업을 서브에이전트에 위임
- **병렬 실행**: 독립적인 작업은 동시에 실행하여 효율성 극대화
- **Todo 추적**: 다단계 작업을 체계적으로 추적
- **백그라운드 실행**: 장시간 작업은 비동기로 처리
- **지속성**: Todo 목록이 비워질 때까지 작업 계속

### 지능형 스킬 활성화

스킬은 상호 배타적이지 않음 - **작업 요구사항에 따라 조합**하여 사용:

| 작업 유형 | 스킬 조합 | 사용 시점 |
|-----------|-----------|-----------|
| 다단계 구현 | `sisyphus` | 기능 구현, 문서 편집 |
| + 병렬 하위작업 | `+ ultrawork` | 3개 이상 독립 작업 |
| + 다중 파일 수정 | `+ git-master` | 3개 이상 파일 변경 |
| 전략적 계획 | `prometheus` | 계획 수립 필요 시 |
| 반드시 완료 | `+ ralph-loop` | 완료가 중요할 때 |

### 활성화 지침

- 명시적 스킬 호출을 **기다리지 않음**
- 작업 유형에 따라 **자체 판단**으로 활성화
- 여러 스킬이 적용될 때 **조합하여** 사용
- 명시적 슬래시 명령은 항상 우선

### 스마트 모델 라우팅

작업 복잡도에 따라 최적 모델 선택:

| 작업 패턴 | 모델 | 이유 |
|-----------|------|------|
| "X 찾기" / "X 위치" | Haiku | 단순 검색 - 빠르고 저렴 |
| "X 추가" / "X 작동 방식" | Sonnet | 모듈 작업 - 균형 |
| "X 디버그" / "X 리팩토링" | Opus | 복잡 - 깊은 추론 필요 |

### 이 프로젝트에서의 활용

보고서 편집 작업에 적합한 에이전트:

| 에이전트 | 용도 |
|----------|------|
| 🔮 **Oracle** | 보고서 구조 분석, 논리적 흐름 검토 |
| 📚 **Librarian** | 참고문헌 정리, 인용 형식 검토, 정책 문서 조사 |
| 🔍 **Explore** | 파일 검색, 패턴 매칭, 용어 일관성 검토 |
| 📝 **Document Writer** | 개선안 작성, 문서 정리 |
| 🔥 **Prometheus** | 대규모 편집 계획 수립 |
| 🎭 **Momus** | 개선안 비평 및 검토 |

### 매직 키워드

프롬프트에 다음 키워드를 포함하면 자동 활성화:

| 키워드 | 효과 |
|--------|------|
| `ultrawork`, `ulw`, `uw` | 병렬 에이전트 오케스트레이션 |
| `search`, `find`, `찾기` | 향상된 검색 모드 |
| `analyze`, `분석` | 심층 분석 모드 |

### 슬래시 명령

| 명령 | 설명 |
|------|------|
| `/sisyphus <작업>` | Sisyphus 멀티에이전트 모드 활성화 |
| `/ultrawork <작업>` | 최대 성능 모드 (병렬 에이전트) |
| `/plan <설명>` | Prometheus와 계획 세션 시작 |
| `/review [경로]` | Momus로 계획 검토 |
| `/deepsearch <쿼리>` | 다중 전략 코드베이스 검색 |
| `/analyze <대상>` | 심층 분석 및 조사 |
