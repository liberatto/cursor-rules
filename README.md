# Rules 워크스페이스

이 저장소는 작업 시 참고할 규칙 문서(.mdc, .md)와 관련 자료를 모아둔 공간입니다. Serena를 사용하기 위해 최소한 하나 이상의 Markdown 파일이 필요하여 `README.md`를 추가했습니다.

## 주요 파일
- `.mdc` 규칙 문서들: 작업 가이드, 계획, 연구, 리포트 작성 규칙 등이 포함되어 있습니다.
- `chats.db`: 대화 기록용 데이터베이스 파일(버전 관리 제외).

## Serena 활성화 메모
- Serena가 프로젝트를 인식하도록 `markdown` 언어를 지정하거나, 이 README와 같이 `.md` 파일이 존재해야 합니다.
- 필요 시 `serena activate --language markdown` 형식으로 언어를 지정해 활성화할 수 있습니다.
