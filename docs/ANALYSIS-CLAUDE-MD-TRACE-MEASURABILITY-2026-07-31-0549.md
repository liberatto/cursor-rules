# CLAUDE.v.5.1 흔적 측정 가능성 인벤토리 및 발동 집계

## 결론

세 가지임.

1. **측정 가능 범위가 좁음** — v5.1의 검사 단위 103개 중 응답에서 발동 흔적을 관찰할 수 있는 것은 **8개(7.8%)**. 나머지 95개는 금지형이거나 사전 행동형이라 흔적이 원리적으로 남지 않음.
2. **0-발동 삭제 후보는 없음** — 측정 가능한 6개 검색어 전부가 실제 트랜스크립트에서 히트. 다만 히트율은 실질 세션 기준 2~20%로 낮음.
3. **부수 발견이 본편보다 중요할 수 있음** — 지시를 **고정 문자열로 못 박은 것만** 한국어 응답에서 원형으로 살아남음. 문장으로 서술된 지시는 한국어로 번역되어 흔적 추적이 불가능해짐(`couldn't verify` 1건 대 `확인하지 못` 20건).

## 1. 측정 설계

### 1.1 데이터

로컬 트랜스크립트 `~/.claude/projects/**/*.jsonl` 전량.

| 항목 | 값 |
|---|---|
| 전체 트랜스크립트 | 1,220개 (62개 프로젝트, 476MB) |
| rules 저장소 세션 | 116개 |
| 분석 대상(rules 제외) | **1,103개** |
| v3.2 배포일(2026-07-10) 이후 | **732개** |
| 그중 Bash 사용 세션 | **289개** (실질 세션 프록시) |
| 그중 Read 사용 세션 | 261개 |

`date` 확인 기준 오늘은 2026-07-31이며, 배포일 절단은 `find -mtime -21`로 수행함.

### 1.2 오염원 배제 — 선행 검증

측정 전 **CLAUDE.md 원문이 트랜스크립트에 주입 기록으로 남는지**를 먼저 확인함. 남는다면 모든 집계가 무효가 되기 때문임.

- `CORE RULES AND STANDARDS` 포함 파일: 전체 42개 → rules 저장소 제외 시 **1개**
- 최근 7일 타 프로젝트 세션 99개 중 포함: **0개**

→ 주입 내용은 기록되지 않음. 히트는 실제 출력만 반영함. rules 저장소의 42건은 문서를 직접 열어 읽은 세션이며, 이것이 자기 언급 오염이므로 전 분석에서 제외함.

### 1.3 분모의 함정

배포일 이후 732개 세션 중 Bash를 한 번이라도 쓴 것은 289개뿐임. 나머지는 한두 턴에 끝난 세션으로, 규칙이 발동할 상황 자체가 없었음. 따라서 히트율은 732가 아니라 **289를 분모로 읽어야 함**.

|---|---|---|---|

> 🔍 통의 8개는 조항을 전수 확인해 확정한 값임. 나머지 95개의 두 통 사이 분할은 **추정 — 미검증**이며, 이 분석의 결론(측정 가능 비율)에는 영향을 주지 않음.

금지형이 흔적을 안 남기는 것은 결함이 아님 — 하지 않은 일에는 증거가 없음. 다만 **문서의 92%가 측정 대상 밖**이라는 사실은 "효과를 측정하자"는 논의의 상한을 정함.

## 3. 2단계 — 발동 집계

### 3.1 결과

배포일(2026-07-10) 이후 732개 세션, 실질 세션 289개 기준.

| 검색어 | 전체(1,103) | 21일내(732) | 실질 세션 대비 | 판정 |
|---|---|---|---|---|
| `AskUserQuestion` | — | 57 | **19.7%** | ✅ 활발 |
| `확인하지 못`(한국어) | 24 | 20 | **6.9%** | ✅ 활발 |
| `assumed — unchecked` | 15 | 14 | **4.8%** | ✅ 살아 있음 |
| `→ verify:` | 16 | 10 | **3.5%** | ✅ 살아 있음 |
| `counter-evidence` | 7 | 7 | **2.4%** | ⚠️ 희소 |
| `likely — because` | 6 | 6 | **2.1%** | ⚠️ 희소 |
| `couldn't verify`(영어) | 1 | 1 | **0.3%** | ❌ 사실상 미발동 |

**0-발동 조항은 없음.** 측정 가능한 것 전부가 최소 1회 이상 히트하므로, 이번 집계로는 삭제 후보가 나오지 않음.

### 3.2 히트의 분포

특정 세션에 몰린 인공물이 아닌지 확인함.

- `assumed — unchecked` 14건 → axplatform 7 · agent-studio 6 · bmad2 1
- `확인하지 못` 20건 → agent-studio 11 · axplatform 6 · bmad2 3

3개 실제 프로젝트에 분산됨. 단일 세션의 반복이 아님.

## 4. 발견 — 고정 문자열만 언어 전환을 견딤

집계에서 가장 선명한 대비는 같은 성격의 두 지시 사이에 있음.

| 조항 | 지시 형태 | 영어 흔적 | 한국어 흔적 |
|---|---|---|---|
| 219행 라벨 | **고정 문자열 지정**(`exact wording`) | 14건 | — (원형 유지) |
| 127행 미검증 보고 | 문장으로 서술(`report "I couldn't verify X"`) | 1건 | 20건 |

응답 언어가 한국어이므로, **문장으로 서술된 지시는 번역되어 원형이 사라짐**. 반면 219행처럼 문자열을 못 박은 지시는 한국어 문장 안에 영어 그대로 박혀 살아남음.

함의는 둘임.

1. **추적 가능성 관점** — 흔적을 남기게 하려면 지시를 서술이 아니라 문자열로 고정해야 함. 지금은 219행만 그렇게 되어 있음.
2. **규칙 정합성 관점** — 219행의 `exact wording` 요구와 한국어 응답 지침이 형식상 충돌하는지 확인이 필요함. 실제로는 한국어 문장에 영어 라벨을 삽입하는 방식으로 양립하고 있으나, 문서 어디에도 그 방식이 명시되어 있지 않음.

## 5. 한계

이 분석이 **증명하지 못하는 것**을 명시함.

- **효과를 재지 않음** — 잰 것은 준수 흔적의 빈도이지, 산출물 품질이 아님. 둘의 상관은 가정임(assumed — unchecked).
- **분모가 여전히 거침** — "실질 세션 289개"는 Bash 사용 여부라는 프록시이며, 각 세션에서 해당 규칙이 발동할 **상황이 실제로 있었는지**는 세지 않음. 따라서 히트율 2%가 낮은 것인지 적정한 것인지 판정할 기준이 없음.
- **mtime 기준 절단** — 세션 시각을 파일 수정 시각으로 대신했으며, jsonl 내부 타임스탬프로 재절단하면 경계 세션 일부가 이동할 수 있음.
- **커밋일 ≠ 배포일** — v3.2 커밋일(2026-07-10)을 배포일로 간주함. 실제 글로벌 파일 복사 시점은 확인하지 못함.
- **모델 교체 미보정** — 기간 내 Opus 4.8 → Opus 5 전환이 있었고, 시계열 비교는 같은 모델 안에서만 유효함.
