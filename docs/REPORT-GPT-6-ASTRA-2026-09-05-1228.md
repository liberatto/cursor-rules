# GPT-6 Astra 신규 출시 보고

> **독립 문서**: 본 문서는 외부 참조 없이 단독 이해 가능하도록 구성. 용어 풀이와 전제를 §0에 인라인.

## 0. 30초 요약

ChatGPT를 만든 미국 회사 OpenAI가 2026년 9월 3일 새 AI 모델 **GPT-6 Astra**를 공개. AI 모델은 회사마다 세대를 올려 가며 내놓는 "두뇌"에 해당하며, 같은 회사의 직전 세대는 GPT-5.6 Sol, 경쟁사 Anthropic의 최신 모델은 Claude Fable 5.1. 이번 모델의 특징은 사람이 시키는 대로 문장을 쓰는 수준을 넘어, **컴퓨터 화면을 직접 보고 마우스·키보드를 대신 조작해 일을 끝내는 능력**에 초점을 둔 것.

> **한 줄 결론**: 컴퓨터 자동 조작·보안 점검·고난도 수학에서는 현재 1위로 확인되나, 종합 지능은 직전 모델과 같은 61점이고 가격은 2.5배로 올랐으므로 **전면 교체 대상이 아니라 특정 업무 한정 도입 대상**.

**용어 사전** (본문에서 반복 등장)

| 용어 | 풀이 |
| --- | --- |
| 토큰(Token) | AI가 글을 세는 단위. 한국어 기준 대략 한 글자에서 두 글자. 요금은 "100만 토큰당 얼마" 형태로 책정 |
| 컨텍스트 창(Context Window) | AI가 한 번에 기억하고 읽을 수 있는 분량. Astra는 105만 토큰으로, 두꺼운 책 여러 권 분량을 한 번에 읽는 수준 |
| 에이전트(Agent) | 질문에 답만 하는 것이 아니라, 목표를 받아 여러 단계를 스스로 진행해 끝내는 AI 사용 방식 |
| 컴퓨터 유즈(Computer Use) | AI가 사람 대신 브라우저·업무 프로그램 화면을 조작하는 기능 |
| 벤치마크(Benchmark) | 여러 AI를 같은 시험지로 채점한 공개 시험 성적 |
| 환각(Hallucination) | AI가 사실이 아닌 내용을 사실처럼 지어내는 현상 |
| API | 사람이 채팅창에 입력하는 대신, 회사 시스템이 AI를 직접 불러 쓰는 연결 통로 |

**본 문서의 근거와 한계**: 아래 수치는 OpenAI 발표 자료를 인용한 언론·분석 매체(TechCrunch·CNBC·Axios·DataCamp·Artificial Analysis 등) 기준. OpenAI 공식 페이지는 접근이 차단되어 원문 직접 확인 불가 상태이며, 수치는 인용 경로를 한 단계 거친 값(🟡 확인 필요). 매체 간 소수점 단위 차이가 있는 항목은 본문에 표기.

## 1. 출시 경과와 사용 가능 범위

- 2026년 9월 3일 보안 검증 파트너(Daybreak 프로그램) 대상 제한 공개로 시작, 9월 4일부터 일반 유료 사용자로 순차 확대
- 사용 경로는 세 가지 — ChatGPT 유료 요금제(Plus·Pro·Business·Enterprise), OpenAI API(모델 이름 `gpt-6-astra`), Amazon Bedrock(아마존 클라우드에서 여러 회사 AI를 골라 쓰는 서비스)
- 기업용 요금제는 **관리자가 켜기 전까지 사용 차단이 기본값**. 회사 계정에서 보이지 않으면 미출시가 아니라 관리자 설정 문제
- 위험도가 가장 높은 보안 기능(취약점 자동 발견·침투)은 일반 공개분에서 제외. 검증된 소수 파트너에게만 개방

## 2. 잘하는 일: 컴퓨터 조작·보안·수학 세 분야에서 1위

시험 성적은 아래와 같음. 숫자는 정답률이며 높을수록 우수.

| 시험 항목 (무엇을 재는가) | GPT-6 Astra | 직전 GPT-5.6 Sol | Claude Fable 5.1 | Claude Opus 5 |
| --- | --- | --- | --- | --- |
| OSWorld 2.0 (컴퓨터 화면 조작) | **72.6%** | 65.7% | 미공개 | 70.2% |
| Terminal-Bench 4.0 (명령어 환경 작업) | **57.7%** | 37.3% | 55.8% | 52.3% |
| FrontierMath Tier 4 (최고난도 수학) | **97.6%** | 83.0% | 87.8% | 73.2% |
| ExploitBench (보안 취약점 공격 재현) | **100%** | 78.5% | 미공개 | 70% |
| 환각 발생률 (낮을수록 우수) | **4.2%** | 12.2% | 미공개 | 미공개 |

- 컴퓨터 화면 조작은 **네 번 중 세 번꼴로 성공**하는 수준(72.6%). 양식 입력·고객관리 시스템 갱신·품질 점검 같은 여러 단계 반복 작업을 사람 지시 없이 끝냄. 직전 모델 대비 소요 시간 47% 단축
- 지어내는 답의 비율이 12.2%에서 4.2%로 감소. 여덟 번에 한 번꼴이던 오답 생성이 스물네 번에 한 번꼴로 줄어든 것이며, 사실 확인 부담이 함께 감소
- 보안 시험 만점(100%)은 **사람 개입 없이 시스템 침투 경로를 만들어 낼 수 있다는 뜻**. 방어 목적으로는 취약점 사전 점검에 유리하고, 반대로 악용 위험도 같은 크기로 증가

## 3. 못하는 일: 종합 지능 정체와 실무 성적 후퇴

AI 회사 발표와 별개로 독립 평가 기관 Artificial Analysis가 자체 측정한 결과는 아래와 같음. 발표 자료에 없던 후퇴 항목이 여기서 확인됨.

- **종합 지능 지수 61점으로 직전 모델과 동일**, 경쟁 모델 Claude Fable 5.1(66점)보다 5점 낮음. 세대를 올렸으나 전반 지능은 제자리
- **실무 직무 시험(GDPval-AA v2)에서 Elo 점수 약 80점 후퇴**. 실제 사무 직군 업무를 재는 항목이므로, 일반 업무 자동화 목적의 교체 근거로는 부족
- 고객 응대, 과학 계산용 파이썬 코드 작성, 긴 문서를 끝까지 따라가는 추론에서 직전 모델보다 낮은 성적
- 종합 시험 Humanity's Last Exam은 57.2%로 Claude Fable 5.1(65.0%)에 뒤짐
- 홍보 수치 중 ARC-AGI-3 99.9%는 **전용 실행 환경을 붙였을 때의 값**이며, 일반적인 API 호출로는 17~63% 수준. 도입 검토 시 이 항목은 그대로 기대하지 않는 것이 안전

## 4. 비용: 성능 상승분보다 가격 상승분이 큼

| 항목 | 요금 (100만 토큰 기준) | 직전 GPT-5.6 Sol |
| --- | --- | --- |
| 입력(AI에게 보내는 글) | $10 | $4 |
| 출력(AI가 쓰는 글) | $50 | $20 |
| 캐시 재사용 입력(같은 자료 반복 사용 시) | $1 | 미표기 |
| 고속 모드 | 2배 요금에 2.5배 속도 | 미제공 |

- 기본 요금이 직전 모델의 **2.5배**. 답변 길이가 10% 짧아졌으나 요금 인상분을 상쇄하지 못해, 같은 작업 하나당 비용은 약 75% 증가
- 입력이 27만 2천 토큰을 넘으면 입력 2배·출력 1.5배의 할증 적용. 대용량 문서를 통째로 넣는 사용 방식은 비용 급증 구간에 해당
- 대량 일괄 처리(Batch)는 절반 요금. 급하지 않은 작업을 모아 돌리면 비용 절감 가능
- 참고 비교: 경쟁 모델 Claude Fable 5.1은 기본 요금이 같은 $10/$50이나 캐시 재사용 요금이 $0.25로 Astra($1)의 4분의 1. 같은 자료를 반복해서 읽히는 장시간 작업에서는 Astra 쪽 비용이 더 큼

## 5. 위험 요소: 판단 과정을 볼 수 없게 된 점

- Astra는 **recurrent depth(재귀 심도)** 방식을 채택. 기존 모델은 답을 내기 전 생각을 문장으로 적어 내려가 사람이 그 과정을 읽고 검증할 수 있었으나, 이 방식은 생각의 일부 또는 전부를 문장으로 남기지 않음. **결과만 나오고 근거 과정 확인 불가**
- OpenAI 수석 과학자는 모델이 강해질수록 생각을 문장으로 남기지 않는 방향이 불가피하다는 입장을 밝힘. 반면 AI 안전 연구자들은 감시 수단 상실을 문제로 제기
- 영국 AI 안전연구소(UK AISI) 점검에서, 유도 질문을 반복하면 안전장치를 우회할 여지가 확인됨
- 보안 안전장치가 정상 업무를 차단하는 사례도 보고됨. 사내 보안 점검·코드 진단 업무에서 작업이 중단될 수 있음
- OpenAI 사장은 이 모델이 사람 수준 범용 인공지능(AGI)의 시작일 수 있다고 발언. **회사 측 주장이며 외부 검증을 거친 판정이 아님**(🔴 추정)

## 6. 선택 기준

- **도입 검토 대상**: 브라우저·업무 시스템 화면을 대신 조작하는 자동화, 사내 보안 취약점 사전 점검, 고난도 수학·계산 검증. 이 세 분야는 다른 모델이 대체하지 못하는 격차 확인
- **도입 보류 대상**: 문서 작성·고객 응대·일반 사무 업무. 종합 지능이 직전 모델과 같고 실무 직무 시험에서는 후퇴했으므로, 2.5배 요금을 정당화할 근거 부족
- **비용 관리 필요 항목**: 대용량 문서를 반복 투입하는 방식은 할증 구간에 걸림. 급하지 않은 작업은 일괄 처리(절반 요금) 적용 권고
- **검증 절차 필요 항목**: 판단 과정을 문장으로 남기지 않으므로, 금액·계약·보안처럼 근거 확인이 필요한 업무에 붙일 때는 결과 검증 절차를 별도 마련 필요
- **권고**: 전사 기본 모델 교체가 아니라, 컴퓨터 조작 자동화 과제 한 건을 골라 4주 규모 시범 적용 후 비용·성공률 실측으로 판단. 근거는 종합 지능 무변화와 요금 2.5배 인상이 함께 확인된 점
